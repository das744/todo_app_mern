
# ToDo App Frontend

React + TypeScript frontend for the To-Do app.

## Setup Instructions

1. Navigate to frontend folder:

    cd frontend

2. Install dependencies:

    npm install

3. Create .env in /frontend:

    REACT_APP_BACKEND_URL=http://localhost:5000

4. Start frontend:

    npm start

5. Open browser:

    http://localhost:3000


### Features

Add a new task (title required)
List all tasks with title, description, and status
Filter tasks by status
Basic stats: total tasks, completed tasks, % completed

### Technologies / Libraries Used

React, TypeScript, Axios, Create React App (CRA)
